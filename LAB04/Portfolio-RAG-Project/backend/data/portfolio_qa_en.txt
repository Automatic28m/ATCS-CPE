[Category: IoT Project]
Q: What is the Air Monitor Pro IoT Mini project and what does it include?
A: Air Monitor Pro is a smart industrial environmental guard that provides real‑time monitoring of air quality, safety thresholds, and early fire detection in warehouses, labs, and other industrial spaces. The system combines a rugged, wall‑mountable ESP32‑based hardware enclosure with a cloud‑based Next.js dashboard. It senses PM2.5 dust, CO₂/Smoke gases, temperature and humidity (4‑in‑1), logs alerts in MongoDB, and sends notifications via MQTT with OTA configuration for sensor thresholds. Local visual and audio alarms (LED and buzzer) are shown on a 16×2 I2C LCD, and the dashboard offers dark/light modes and 7‑day historical analytics. The hardware uses an ESP32 microcontroller, DHT22 sensor, Sharp GP2Y1010AU0F PM2.5 sensor, MQ‑Series gas sensor, and a 16×2 LCD. The project was presented at RMUTT on March 14 2026, and you can view it at https://airmonitorpro.netlify.app/ or explore the source code on GitHub at https://github.com/Automatic28m/air_monitor_iot.

[Category: Web Development]
Q: What is the Thaivel tourism website project and what are its main features and technologies?
A: Thaivel is a sophisticated full‑stack travel platform created as a showcase for the International Web Design Contest (iWDC). It serves as a curated gateway to Thailand’s attractions, organizing destinations by the country’s six regions and allowing users to filter by categories such as cafes, nature spots, restaurants, street food, temples and urban sites. Key features include a regional exploration guide, a smart categorization engine, the “Tuktuk Driver AI” conversational travel assistant, dark‑themed interactive maps with custom pins, a mobile‑first responsive design, and social‑media and Google Maps integration for each location. The site was built with Next.js (React) on the front end, styled with Tailwind CSS, and uses MySQL for the destination database. It was presented at RMUTT on 7 April 2026 and the source code is available at https://github.com/Automatic28m/thaivel.
